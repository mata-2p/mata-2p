### 🔭 Código abierto

#### [Mirador](https://github.com/mata-2p/mirador)

Un dashboard web local que sigue a los agentes de programación que corren en tu máquina, carpeta por carpeta, para tener varios a la vez sin perderle el hilo a ninguno.

- Muestra qué agente te está esperando y dónde quedó cada proyecto.
- Abre varios agentes sin llenar la memoria y los trae de vuelta después de un reinicio.
- Sin telemetría ni cuentas. Funciona con Claude Code, pi, opencode o cualquier agente de terminal.

`TypeScript` · `Apache-2.0` · versión 0.2.0, con instalación de una línea en Linux

#### [pi-context-guard](https://github.com/mata-2p/pi-context-guard)

Dos extensiones para [Pi](https://pi.dev) pensadas para sesiones largas de programación:

- `context-guard` compacta la sesión en un umbral que no depende del modelo, y antes le pide al modelo que guarde un resumen de la sesión en Engram.
- `context-observer` registra métricas de contexto y compactación, nunca el contenido, para ajustar ese umbral con datos propios.

`JavaScript` · `MIT` · [disponible en npm](https://www.npmjs.com/package/pi-context-guard)

### Hi, I'm Matías Barría 👋

**Software engineer · Founder of [ZURAI](https://zurai.cl)** · Rancagua, Chile

I build open-source tools for working with coding agents and, through ZURAI, custom software with **.NET**, **TypeScript** and **Azure**.

**Open source**

- **[Mirador](https://github.com/mata-2p/mirador)**: a local web dashboard that keeps track of the coding agents running on your machine, folder by folder, so you can run several at once without losing the thread of any of them. No telemetry, no accounts. TypeScript, Apache-2.0, version 0.2.0.
- **[pi-context-guard](https://github.com/mata-2p/pi-context-guard)**: two [Pi](https://pi.dev) extensions for long coding sessions. One compacts the session at a model-independent threshold after asking the model to save a session summary to Engram; the other records context metrics so you can tune that threshold. JavaScript, MIT, on npm.
- Go code merged into [gentle-ai](https://github.com/Gentleman-Programming/gentle-ai).
